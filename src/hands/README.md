# Generated hands in the app

Load a MIDI piece in Create, then enable **Settings → Hands & labels → Ghost hands**.
The opacity control applies to both preview and video export. Live MIDI alone
does not provide the look-ahead timeline required by this planner.

`anatomicalPerformance.ts` converts the app project to timed finger events,
preserving tempo changes and manual finger assignments without modifying notes.
The app uses zero lead-in; the separate study retains its one-second lead-in.
`anatomicalHandMotion.mjs` supplies the same articulated rig and motion to the
study and `AnatomicalHandsLayer`. `ThreeRenderer` uses that layer for live frames,
seeks and offline export. The GLB is bundled locally, with its MIT license in
`src/assets/hands/LICENSE.md`; no network service or new dependency is required.

Both display axes use the keyboard width to scale the mesh, avoiding stretched
hands when the canvas is resized. Enabling hands also uses a physically
proportioned keyboard, including in portrait exports, and keeps pointer key
hit-testing and the falling-note hit line aligned with that layout. The app awaits the asset before reporting
renderer readiness. Invalid arrangements show an app error; exporting with
unavailable requested hands fails explicitly rather than silently omitting them.

This integration is not a claim of fully realistic fingering. Wide left-hand
transitions still have measured contact errors of roughly 8–10 mm in the study.
Finger collision avoidance and full forearms are not implemented. Existing Showcase videos are not regenerated by this change.
