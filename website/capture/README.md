# Actual app media

Captured October 16, 2026 from the production React components and Three.js renderer through the app's Vite development preview. No generated product UI or composited controls.

Run `npx vite --config vite.renderer.config.ts --host 127.0.0.1 --port 5174` from the parent app directory, then open `/website/capture/index.html`. This helper loads the existing test MIDI through the real parser, spatial index, store and playback engine. It is outside the Next.js routes and public directory.

## Motion clips
Three 12-second silent captures of the actual WebGL canvas at 30fps: blue, tutorial, and amber. These use different passages of the same bundled MIDI, not three different pieces. Capture with the staging buttons, download WebM, and transcode with the existing ffmpeg-static binary to H.264 MP4 (CRF 21, yuv420p, faststart). Posters are extracted from each clip at 2 seconds. Editing, recording, score, and export media remain real still captures. No camera footage is simulated.

Corrected capture framing: dedicated 1280x720 CanvasArea (actual app component), keyboardHeightRatio 0.22. Full canvas recorded without cropping or nonuniform scaling. Wide clips and posters replace the earlier narrow sidebar-sized recordings. WebM and MP4 are provided; the website frame uses the matching 16:9 ratio.

Showcase upgrade: 18-second Concert Gem and Aurora Glass recordings from later passages of the same MIDI. Actual presets with note glow reduced to 75 and particle density 45/glow 100/size 70. Captured at native 1920x1080, requested 30fps and 16Mbps. MP4 uses CRF 17; no upscaling, fabricated UI, or added postproduction effects. Silent by design.
