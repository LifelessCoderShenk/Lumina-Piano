# Website hand preview

The Showcase page loads the silent hand study on demand from `/demos/hands/index.html`.
It is self-contained: no capture server or external CDN is required. MIDI imports run locally in a worker.

After changing the shared hand motion, planner, or study controls, rebuild the checked-in static files from the repository root:

```sh
node website/scripts/build-hand-demo.mjs
```

This uses the app's existing esbuild and Three.js dependencies. Normal website builds use the generated files and do not require the app dependencies. Commit the generated files with source changes. The hand model license and bundled library notices are included alongside the demo.

The existing recorded performance video is separate and is not regenerated by this command.
